# BeeHive Web Design Lab

Static visual exploration for BeeHive.Partners.

Key review page: [design-lab.html](design-lab.html)

This repository contains design prototypes. The concepts are not production. Prices and placeholder companies are not final. MUSKLE is used only as the current development example. No backend is included.

`index.html` is the baseline landing page (V1). It is not replaced by the experiments. Start a design review from `design-lab.html`.
