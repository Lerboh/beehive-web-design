# GitHub review workflow

GitHub Pages is a design-review environment for the static BeeHive prototype. It is not the production site.

1. Cursor edits the design locally.
2. Cursor tests the pages locally.
3. Commit the change.
4. Push to GitHub.
5. GitHub Pages updates from the `main` branch.
6. Dirk gives ChatGPT the live design-lab URL.
7. ChatGPT reviews the rendered pages.
8. The next design iteration is committed and pushed the same way.

Do not point beehive.partners at this site, change Render, change production DNS, or add a backend here.
