# BeeHive brand system

The two supplied marks are the BeeHive logos. They are brand assets, not interface icons.

Phosphor Regular remains the interface icon system. Do not replace these logos with Phosphor icons, and do not redraw, recolor, or add text to the image files.

## BEEHIVE LOGO SYSTEM

- Business identity = clean hive logo without bees.
- Partner identity = hive logo with bees.
- Shared platform uses the clean core mark as neutral default.
- Partner-route moments may explicitly use the bee version.
- These raster/logo assets must never be replaced by interface icons.

## Files

| Role | File |
| --- | --- |
| Business original | `assets/brand/beehive-business-logo.png` |
| Partner original | `assets/brand/beehive-partner-logo.png` |
| Business, outer white removed | `assets/brand/beehive-business-logo-transparent.png` |
| Partner, outer white removed | `assets/brand/beehive-partner-logo-transparent.png` |

The originals keep the white field from the supplied files. The transparent files only clear the white that connects to the edge of the canvas. The hive, frame, opening, and bees are unchanged. Gold and black are not recolored.

Pages use the transparent files. On dark forest sections and full-bleed heroes, the mark sits on a white tile so the black frame stays visible.

## Where each mark appears

- Shared homepages: clean hive in the header and footer, beside the HTML wordmark `BeeHive.Partners`.
- Choose your side: clean hive on For Businesses, hive with bees on For Partners.
- Business pages: clean hive in the header, hero, and signup.
- Partner pages: hive with bees in the header, hero, and signup.

The wordmark is HTML text. It is not baked into the image.

Header marks beside the wordmark use empty alt text. A mark that carries the identity on its own uses `BeeHive Business` or `BeeHive Partners`.
