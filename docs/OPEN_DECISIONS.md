# Open beslissingen

Alleen punten die in deze stap daadwerkelijk open zijn. De werkmap bevatte geen eerdere besluiten.

| Onderwerp | Status | Beslissing nodig |
|---|---|---|
| Definitief logo | Geen logobestand in de werkmap | Ja |
| Referentieafbeelding | In de opdracht genoemd, niet in de werkmap aangetroffen | Aanleveren als die de stijl nog moet bijsturen |
| Definitieve kleuren | Proefwaarden in `css/tokens.css` | Ja |
| Definitieve fonts | Geen fontbestanden; system stack als proef | Ja |
| Mascotte | Geen bestand; niet gebruikt in de proef | Ja, inclusief of een mascotte gebruikt wordt |
| Homepage en paginastructuur | Nog niet bouwen; wacht op stijlfeedback | Ja |
| Namen en voorwaarden van de vier partnerfases | Niet bevestigd in projectbestanden | Ja |
| Installatie- / setupfee | Niet bepaald | Ja |
| Abonnementsprijzen | Niet bepaald | Ja |
| Abonnementsnamen | Niet bepaald | Ja |
| Limieten en functies per abonnement | Niet bepaald | Ja |
| Hostingarchitectuur | Niet vastgelegd | Ja |
| Database-isolatie per bedrijf | Principe vastgelegd: gegevens niet mengen. Techniek open | Ja |
| Functies bij launch | Niet vastgelegd | Ja |
| Fotografie, bedrijfsbeeld, partnerbeeld | Niet aanwezig | Ja |
| Taal en vertaling | Engelse proefteksten; geen vertaalsysteem | Later |
